# Windows 11 acceptance checklist

This is an acceptance checklist for scenarios requiring real devices/apps or a clean Windows image. An automated build does not mean every item below has been executed; record results and the exact tested version separately.

Record the artifact SHA256, OS build, display models/scales and app versions before testing. Start with recording and autosave off. Use synthetic test text/images, not passwords or personal files.

1. **Clean machine:** extract portable ZIP and run Cyclop.exe on a Windows 11 x64 VM with no .NET SDK/runtime, Python or GPU runtime installed. Also install Setup.exe as a standard user; no UAC prompt, no autorun unless later opted in. Verify uninstall removes program files/autorun entry and leaves local user data. Installer/executable are unsigned.
2. **Window/focus:** keep a caret active in Notepad. Hover the top strip: panel opens after 180ms and Notepad keeps focus. Move away: closes after 450ms. Hover across tab icons and dwell on each: the current section stays selected. Activate an icon by click or keyboard to switch. Click translation/search and type RU/EN, Ctrl+A/C/V/Z; fields get focus only explicitly. Escape closes. Test configurable Ctrl/Alt hotkey and conflict feedback. Launch second instance: existing one opens; only one tray entry remains.
3. **Hit testing:** while collapsed, click a window immediately below the strip; it receives the click. Test the transparent shoulder/corner areas. No full-display transparent window should exist. Alt+Tab and taskbar show no Cyclop entry. Open a context menu and move outside: panel stays until menu closes.
4. **Explorer drop:** create two disposable files. Drag both onto collapsed strip; panel opens Shelf, Copy cursor. Select with Ctrl/Shift, drag into another folder; originals remain and copies appear. Open, reveal, copy path, remove card. Delete/move original separately: card shows unavailable. Removing cards never deletes originals.
5. **Clipboard:** explicitly enable text recording; copy synthetic Unicode text and a URL. Both appear and can be searched, pinned, restored, deleted and cleared. Copy an image and a multi-file list: neither appears in text history; image auto-save only adds to the separately opted-in shelf. Existing legacy image/file rows are hidden and never reappear in search; no automatic deletion is expected. Restore produces no duplicate history or shelf loop. Restart and restore previous text. Inspect SQLite with strings: no original payload, previews, image bytes, hashes or plaintext index. Changing Windows account must prevent DPAPI decryption. Capture pause and item/age limits work.
6. **Privacy markers/busy buffer:** producer writes exclusion format or registered CanIncludeInClipboardHistory DWORD=0 plus payload. Neither history nor autosaved shelf receives it. Repeat DWORD=1 without exclusion: capture permitted only with explicit opt-in. Hold OpenClipboard temporarily, then release: bounded async retry, no frozen UI. Keep it locked beyond retry budget: app skips safely. Use tools/probe-clipboard.ps1 when available to test real formats with temporary synthetic data.
7. **Lightshot:** enable image autosave after reading ordinary-PNG warning. In installed Lightshot take a screenshot → Ctrl+C. Exactly one card appears, with unknown clipboard source (not falsely attributed to Lightshot). Save same image to chosen watched folder: pixel dedup leaves one card. Test both clipboard PNG and standard Bitmap. Disable capture: autosave remains a separate explicit setting. Clear history: saved PNG remains. Burst saves, partially written PNG and watcher overflow recover without duplicate cards. Storage cleanup touches only managed retained PNGs, never user originals.
8. **Spotify:** test desktop and Store installations independently. Start playing; real title, artist, cover, timeline and supported buttons update. Switch browser playback: Cyclop retains Spotify. Try pause/prev/next/seek only if enabled; verify Try failures surfaced. Test ad, missing artwork, stopped state, exit/restart Spotify and session replacement. Do not treat an absent-session probe as a playback test.
9. **Translation:** install/import both pinned Argos 1.9 models explicitly, then disable network externally. Reboot VM. On first launch translate English→Russian and Russian→English, blank/multiline text, long paragraphs and mixed script/manual direction. Check no hidden downloads, HTTP listeners, Python requirement or Torch/CUDA. Change input rapidly: stale result cannot replace latest. Kill worker mid-request: error and next-request recovery. Idle >90 seconds: worker exits; next translation starts a fresh process. Missing one/both models leaves other modules usable. Wrong hash/oversized/traversal archive is rejected without replacing a good install.
10. **Displays/power:** two or more monitors, mixed 100/150/200%, taskbar at top/bottom, negative coordinates. Move selected screen, change resolution/scale, unplug/replug it: panel follows or falls back safely. Sleep/wake: position/media/clipboard watch recover. Fullscreen app on chosen monitor hides panel, another monitor's fullscreen does not; restore foreground restores collapsed panel. Protected desktop remains untouched.
11. **Performance:** tools/measure-idle.ps1 with shell PID, collapsed and no translation. Repeat worker PID after both models are loaded, then idle. Record total-core-normalized CPU, working/private bytes, duration and conditions; never infer measurements from code. Confirm worker disappears after idle timeout, progress timer stops when pane hidden, and no animation clocks remain when playback is paused or the music pill is hidden/expanded. Separately measure the visible playing capsule.
12. **Music capsule:** while Spotify plays, collapse the panel: circular current artwork and five moving bars appear in a rounded capsule. Hover/click opens the usual controls through the centered geometry reveal; moving away reverses it. Rapidly leave/re-enter mid-transition: no jump, eventual correct compact/expanded bounds, no lingering clocks. Hotkey/Escape and reduced motion switch immediately. Confirm no clipped labels during growth and no invisible area blocking other apps outside the visible shape. Pause or close Spotify: the thin strip returns. Change tracks: artwork updates. Check missing-artwork fallback, reduced motion in app and Windows, and fullscreen/sleep hiding. The bars indicate playback and do not follow actual sound amplitudes.
13. **Spotify volume:** compare the panel with Spotify's per-app level in Windows Volume Mixer. Drag and use keyboard arrows/Home/End; readback and percentage agree. A positive adjustment unmutes at the requested level, not a previous loud level. Change Spotify in the mixer externally; Cyclop follows. Other applications and system master volume stay unchanged. With no Spotify audio session, the slider is disabled and shows an em dash. Check paused/inactive sessions, mute, multiple outputs/routing, output removal and sleep/resume. During a continuous drag updates are coalesced and pointer leave does not collapse the panel before release. Never use a probe that has not passed the ABI contracts; the default volume probe is contract-only.
14. **Compact player actions:** Spotify opens at 520 × 180 DIP, with a 96px cover, one control row and elapsed/remaining time. Long metadata truncates inside the pane. Click or keyboard-activate the speaker twice: mute then restore the same mixer level. Set the slider to zero after observing a nonzero level, then click the speaker to restore it. A fresh unknown-zero session must not jump to a guessed level. Rapidly drag then click mute: the speaker is disabled until pending writes finish. Click/keyboard-activate the cover while Spotify is normal, minimized, closed to tray and not running; the existing client is shown or its registered app is launched, with no browser or playback command. Confirm Spotify gets foreground on a real user gesture. Switch the four main panes: each remains 520 × 180 DIP. Open Settings: it grows down to 520 × 420 DIP, and shrinks when leaving, keeping the top edge/player content fixed. Reverse repeatedly during reveal: both outline and height settle without a jump. Scroll to the final shelf card, clipboard entry, long translation line and last Settings action; each stays reachable.

15. **Shelf cleanup and wheel:** with several cards, scroll over a card using the mouse wheel in both directions and verify edge clamping and unchanged selection. Click the shelf trash button: all cards disappear and originals/managed PNGs remain on disk. Delete saved managed screenshots externally while the panel is open and collapsed, then reopen; cards disappear without unavailable placeholders. Restart after deleting screenshots while Cyclop is closed. Delete/rename and recreate the managed folder, save a new screenshot and delete it again; watching resumes. An inaccessible ordinary file reference stays on the shelf.

16. **Apple-style controls:** type a long clipboard search and clear it using its inline close button; text must align with its placeholder in both X and Y and never overlap that button. Clearing the query preserves history; the adjacent trash clears history. Tab through controls: blue focus stays visible. Toggle settings with Space; use arrows/Enter/Escape in language/monitor menus. Test number edits, shortcut capture, translation selection/copy and both scrollbar grips/page areas at 100/150/200% scaling. Check selected/disabled/hover states and dark tray/shelf menus. The black capsule remains; main panes are 520 × 180 and Settings is 520 × 420 DIP.

17. **Settings drawer:** test opening from the collapsed strip and playing music pill, rapid Settings/main-pane reversals, Escape, fullscreen/sleep hiding and display changes during the height animation. Top edge remains fixed; text stays sharp and unscaled. Enable app reduced motion or disable Windows animations: size changes immediately. On a short work area, Settings remains within it and the last action is reachable by scrolling.

18. **Section crossfade:** click each section, then repeat rapidly and reverse mid-transition. The last selection wins without a blank flash or queued transitions. Re-clicking the selected icon does not replay the fade. Outgoing controls cannot be clicked or reached by Tab; the incoming section remains usable. Text and scroll positions survive. Open/leave Settings while content fades, and switch during a music reveal. Escape, hide/fullscreen and reduced motion clear pending fades; Ctrl+1…4 stays immediate.

19. **Translation spacing:** verify language/swap and Models/copy gaps, the gap above/between editors and the full centered Models caption at 100/150/200% scale. Mouse focus and an open language menu keep neutral field borders with a soft fill change. Tab still shows a rounded focus cue; typing/selection/caret, language keyboard navigation, Models action and long-text scrolling remain usable.
